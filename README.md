# 📊 Application Feedback Cours

Application web de feedback anonyme pour cours de physique-chimie.

## 🎯 Fonctionnalités

- ✅ Vote anonyme avec smileys
- ✅ Gestion multi-sessions
- ✅ Statistiques temps réel
- ✅ Export CSV
- ✅ Interface responsive (iPad)
- ✅ Code admin sécurisé

## 🛠️ Technologies

- **Frontend** : HTML5, CSS3, JavaScript
- **Backend** : PHP 7.4+
- **Graphiques** : Chart.js
- **Hébergement** : InfinityFree

## 📦 Installation

1. Cloner le repository
2. Créer le dossier `data/`
3. Uploader sur serveur web PHP
4. Accéder à `index.html`

## 🔒 Sécurité

- Rate limiting (10 votes/min)
- Code admin hashé (bcrypt)
- Protection CSRF
- Validation des entrées
